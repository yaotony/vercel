# 臺灣健保補充保費改革概述

本文主要報導臺灣衛福部計畫修訂全民健康保險（健保）中**補充保費**的收取方式，尤其針對股利、利息及租金收入設定年度累計門檻。此次修法預計影響約480萬名民眾。

現行制度採用單筆收入超過新台幣2萬元即課徵補充保費（2.11%），而未來將改為年度結算，累計金額一旦超過2萬元就必須繳納補充保費。改革計劃於2025年動議，預計在116年（2027年）正式實施，目的在於強化健保財務公平性與可持續性。

此次改革引起存股族、定存族與包租公等族群強烈反彈，指控政策不公平、變相加稅。衛福部長石崇良則強調，此政策立基於互助精神，期望讓有能力者承擔相對較多的保費，維繫台灣健保基金財務健康。在人口高齡化及薪資保費比例下降的財務壓力下，修法成為必然選擇。

# 健保補充保費制度的核心變革

## 補充保費的課徵基礎調整

此次改革的核心是**從單筆計算改為年度累計**。意即將所有非薪資所得，包括股利、利息、租金及高額獎金進行全年合計，只要累積超過2萬元新台幣，就須繳納補充保費2.11%。

而現行制度採用的「單筆超過2萬元才課稅」設計，易遭拆分多筆低於門檻收入，形成逃漏稅漏洞。年度累計有助於封堵此漏洞，提升財務公平。

## 補充保費的適用範圍

補充保費的六大適用收入包括：

- 高額獎金（超過月投保薪資4倍）
- 兼職收入
- 執行業務收入
- 股利收入
- 利息收入
- 租金收入

此次修訂特別針對股利、利息、租金採年度累計方式，與傳統逐筆超過2萬元課徵的規定有本質差異。

## 政策基準與公平理念

衛福部長石崇良強調以**「能力負擔」原則**為基準，讓負擔更合理分攤。例如獎金起徵門檻以最低薪資4倍設立，修正過往高薪者門檻過高、低薪者負擔過重的現象。

# 政策優勢與挑戰分析

## 政策優勢

- **增加健保財源**：估計將增加100至200億元收入，因應高齡化醫療支出壓力。
- **提升財務公平性**：避免拆單逃漏稅，讓高額非薪資所得者承擔合理費用。
- **符合國際趨勢**：多國均對資本利得設有課稅制度，臺灣政策接軌。
  
## 挑戰與爭議

- **中產階級反彈強烈**：存股族、定存族、包租公感受到額外負擔，質疑政策不合理。
- **低門檻可能影響投資意願**：股市與定存波動恐使民眾抗拒理財行為。
- **影響弱勢族群及小資族**：政策落實需考慮避免過度負擔弱勢群體。
- **法律細節仍待完善**：目前仍在廣納意見階段，配套措施待調整。

# 深度觀點與未來展望

## 政策的必要性與合理性

從實務面看，此次改革能有效填補過去按單筆計算所產生的課徵漏洞，提升全民健保基金的公平性與永續性。針對股利與租金收入採年度累計機制，有助鼓勵合規申報，符合全球資本所得課稅趨勢。

## 對中產階級的衝擊與政策建議

然而，中產階級尤其是依賴股息、租金收入的族群負擔顯著，可能打擊其投資熱情與退休準備。政府應設計更細緻配套，如：

- 設置合理免稅額，保護小額投資族群
- 推動分級稅率，緩和負擔差異
- 提供理財與稅務諮詢，協助個別調整投資策略

## 未來政策面向

政策施行後，應持續監測社會反應及經濟影響，考慮是否擴展納入更多非薪資收入項目。政府需強化透明溝通，提升財務透明度與健保使用效率，減輕社會政治壓力。

# 總結與實務建議

臺灣衛福部健保補充保費制度由單筆課稅轉為年度累計制度，雖引發爭議，卻有助維繫健保財務公平與永續。對民眾與政府均提出以下建議：

1. **加強政策溝通與民眾教育**：說明改革必要性與長遠效益。
2. **設置合理免稅額度**：保護小額收入與弱勢族群。
3. **調整分級費率結構**：使課徵更符合不同所得群體能力。
4. **提供配套理財與稅務建議服務**：協助民眾因應改革調整策略。
5. **滾動式政策調整與反饋機制**：根據社會反饋持續優化制度。

民眾應主動了解自身非薪資所得狀況，提前規劃資產與報稅事宜，並積極參與政策意見表達，促使公平與效率共存。

此改革不僅是個人財務規劃必須面對的挑戰，也是全民健保永續的重要關鍵。
